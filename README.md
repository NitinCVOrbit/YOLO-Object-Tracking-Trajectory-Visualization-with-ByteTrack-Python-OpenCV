# 🚀 YOLO26 Object Tracking & Trajectory Visualization

Track multiple objects and visualize their movement in real time using **YOLO26, ByteTrack, and OpenCV!**

This project detects and tracks objects across video frames, assigns unique tracking IDs, and displays colorful trajectory trails to visualize their movement.

### ✨ Features
- Real-time object detection using YOLO26
- Multi-object tracking with ByteTrack
- Unique ID assignment for each tracked object
- Color-coded bounding boxes and tracking IDs
- Center point detection for each object
- Trajectory history and movement visualization

### 🛠️ Technologies
- Python
- Ultralytics YOLO26
- ByteTrack
- OpenCV
- NumPy
